# 한영 의료용어 매핑 RAG

한글 의료 질의를 표준 영문 의학용어로 매핑한 뒤, 영문 문헌(PubMed)과 한글 건강정보(질병관리청)를 함께 검색해 **출처를 인용한 한글 답변**을 만드는 하이브리드 RAG 파이프라인입니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2026.09 ~ 2026.10 (완료, 검색 단계 검증까지) |
| 형태 | 개인 프로젝트 (전체 단독 수행) |
| 대상 질환 (MVP) | 당뇨병 — 용어·코드 체계가 잘 정리되어 파이프라인 검증용으로 선정 |
| 포트폴리오 | [Notion 상세 페이지](https://www.notion.so/Portfolio-AI-356a28e78b6f818f96d1c1e040fbdc38) |

## 왜 만들었나

국내 임상 커뮤니케이션은 한글이지만, 근거가 되는 논문·가이드라인·표준 용어체계(MeSH, ICD-10 등)는 대부분 영문입니다. 영문 단일언어 RAG에서 한 걸음 나아가, 한글 질의 → 표준 영문 용어 매핑 → 검색 → 한글 응답까지 연결하는 것이 목표입니다.

## 파이프라인

```
한글 질의
  ↓ 용어 추출 — 사전(95,673건)에서 긴 용어 우선 매칭
  ├─ [영문 경로] 사전 매핑을 힌트로 Ollama(gemma2:9b)가 검색어 번역·보완
  │     → all-MiniLM-L6-v2 → Chroma (PubMed 리뷰 194건)
  └─ [한글 경로] 원문 그대로 paraphrase-multilingual-MiniLM-L12-v2
        → Chroma (질병관리청 문서 6건, 231개 청크)
  ↓ 두 경로 결과 병합
  ↓ Ollama — context 안의 내용만 근거로 한글 답변 + 출처(PMID/출처명) 인용
  ↓ "진단·처방 대체 아님" 안내문 강제 포함
```

Ollama 서버가 꺼져 있으면 `is_ollama_running()`으로 감지해 사전 매핑 단순 결합으로 자동 폴백합니다.

## 핵심 설계 — 사전 병합 우선순위

| 순위 | 사전 | 이유 | 필터링 |
|---|---|---|---|
| 1 | KCD 상병마스터 | 공식 질병분류명 (47,798건) | 한글명·영문명 모두 있는 행만 |
| 2 | KOSTOM V7.0 | UMLS/SNOMED CT 코드 포함, 커버리지 넓음 | 33.9만 행 중 KCD 코드 보유 9.6만 건 |
| 3 | AI Hub 용어사전 | 일반 의학용어 보강 (1,822건) | domain == "의학", 검수 안 된 자료라 최하위 |

한글명이 겹치면 우선순위가 높은 출처를 채택합니다. 문장 내 용어 추출에서는 1글자 용어를 제외해 "대사" 안의 "사"가 잘못 매칭되는 문제를 막았습니다.

## 결과 — 검색 단계 Recall@3 (자체 평가셋 15문항)

| 검색어 구성 | Recall@3 |
|---|---|
| 사전 매핑 용어만 결합 | 5/15 = 33.3% |
| 사전을 힌트로 LLM이 번역·보완 | **15/15 = 100%** |

사전만으로 실패한 원인은 사전이 **진단명 위주**라서 해부학 용어("족부"), 약물 계열("혈당강하제"), 최신 약물명("인슐린 아이코덱"), 면역·세포생물학 용어("B림프구", "장내미생물")가 없었기 때문입니다. 이 빈틈을 LLM 번역으로 보완했습니다.

> 이 수치는 **검색 단계만** 측정한 것이며, 평가셋도 직접 만든 15문항 소규모 셋입니다. 답변 생성 품질은 이 프로젝트의 평가 범위에 포함하지 않았습니다.

## 알려진 한계와 향후 개선 방향

이 프로젝트는 검색 단계의 문제를 찾아 고치는 데까지를 범위로 마무리했습니다. 확장한다면 다음 작업이 남아 있습니다.

- 답변 생성 품질 평가 — 인용이 실제 context와 일치하는지, 안전 문구가 매번 포함되는지
- 한글 코퍼스(KDCA) 경로의 검색 정확도 평가
- 평가셋을 다른 질환군으로 확장
- KOSTOM 약어 영문명(예: 당뇨병 → "DM") 후처리, AI Hub 오타 정제

## 코드 구조

```
1_build_term_dictionary.py   상병마스터 + KOSTOM + AI Hub → 한영 용어 사전 통합
2_term_lookup.py             용어 조회(정확/유사 매칭) + 문장 내 용어 추출
3_build_corpus.py            PubMed E-utilities로 영문 코퍼스 수집
4_build_vector_db.py         영문 코퍼스 임베딩 → Chroma
5_generate_answer.py         한글 질의 → 용어 매핑 + LLM 번역 검색 → 답변 생성
6_evaluate.py                평가셋 기반 Recall@k 자동 채점 (실패 문항은 기대/실제 PMID 출력)
7_build_kr_corpus.py         국가건강정보포털 한글 문서 원문 수집
8_build_kr_vector_db.py      한글 문서 청킹 + 다국어 임베딩 → Chroma
```

## 실행

```bash
pip install -r requirements.txt
ollama pull gemma2:9b          # 선택 — 없으면 사전 매핑 폴백으로 동작

python 1_build_term_dictionary.py
python 3_build_corpus.py && python 4_build_vector_db.py
python 7_build_kr_corpus.py && python 8_build_kr_vector_db.py
python 5_generate_answer.py
python 6_evaluate.py           # data/eval/eval_set.jsonl 필요
```
